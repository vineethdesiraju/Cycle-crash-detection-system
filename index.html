What It Does

Built for speed.
Designed for safety.

Every component of CycleGuard is purpose-built to detect, log, and alert — in under 200 milliseconds.

💥
Crash Detection
MPU6050 measures G-forces across all 3 axes. A sudden spike beyond the threshold triggers the crash handler instantly.
🔊
Instant SOS Buzzer
The piezo buzzer fires a distinct SOS pattern the moment a fall is confirmed. Audible up to 15 meters.
📡
Live Serial Stream
ESP32 broadcasts JSON telemetry over USB Serial at 9600 baud — readable by any connected laptop or server in real time.
🌐
Web Dashboard
A Web Serial API dashboard connects directly to the device. No drivers, no app — just open the browser and click Connect.
📊
Telemetry Graphs
Live-plotted X/Y/Z acceleration over time, gas PPM bar, battery level, and GPS coordinates updated every 100ms.
⚡
Simulation Mode
No hardware? Use the browser simulator to inject crash events, test the detection thresholds, and demo the full system.

System Flow

From fall to alert
in four steps.

01
Sensor Reading
MPU6050 measures acceleration 100× per second. Data is read over I2C by the ESP32.
02
Threshold Check
If G-force > 2.5g on any axis, the crash detection routine fires. Configurable debounce prevents false positives.
03
SOS Trigger
Buzzer activates, crash event logs to serial, LED flashes red. GPS coordinates captured if available.
04
Dashboard Alert
Web dashboard receives the event via Web Serial, shows full-screen SOS overlay, logs timestamp and coordinates.
